# Лабораторная работа №3 — система управления учебными курсами

Веб-приложение на Express.js и EJS для просмотра, поиска, добавления, редактирования и удаления учебных курсов.

## Запуск

```bash
cd /Users/evgheniidolomanji/IdeaProjects/node-univer/lab3_evgheni_dolomanji
npm install
npm start
```

Откройте <http://localhost:3000>. Если порт занят: `PORT=3001 npm start`.

## Возможности

- список из пяти исходных курсов;
- поиск по названию или преподавателю без учёта регистра;
- фильтрация по семестру и одновременное использование поиска с фильтром;
- просмотр, создание, редактирование и удаление курсов;
- серверная валидация формы с сохранением введённых значений;
- журналирование всех запросов;
- страницы 404 и 500 без вывода технических ошибок пользователю.

## MVC-структура

- `models/courseModel.js` — массив данных о курсах;
- `controllers/courseController.js` — обработка запросов и операции с курсами;
- `routes/courseRoutes.js` — маршруты приложения;
- `middleware/` — логирование и валидация;
- `views/` — EJS-шаблоны и повторно используемые partials;
- `public/css/style.css` — стили интерфейса.

## Маршруты

| Метод | Адрес | Назначение |
| --- | --- | --- |
| GET | `/` | Перенаправление на `/courses` |
| GET | `/courses` | Список, поиск и фильтрация |
| GET | `/courses/new` | Форма создания |
| POST | `/courses` | Создание курса |
| GET | `/courses/:id` | Страница курса |
| GET | `/courses/:id/edit` | Форма редактирования |
| POST | `/courses/:id/edit` | Сохранение изменений |
| POST | `/courses/:id/delete` | Удаление курса |

Данные хранятся в памяти, поэтому после перезапуска приложения изменения не сохраняются. Перед сдачей замените `YOUR_GROUP` в `views/partials/footer.ejs` на номер своей группы.
